科研基础环境准备

网站课程与代码实践优先使用 Kaggle。本地 Python 环境适合准备长期编程、处理私有数据、复现复杂项目或连接服务器的学习者。

打开 Kaggle

完成网站课程和实践

使用 Kaggle 复制公开 Notebook，按单元格运行和修改。平台已经准备常用 Python 库，并可按账户当前设置选择可用计算资源。

准备长期科研

继续配置 Python 3.13、独立虚拟环境、VS Code、Jupyter、Git 和远程连接。具体项目已有环境文件时，使用项目指定版本。

访问与账户

先在浏览器中打开 Kaggle，确认主页、登录页和 Notebook 页面能够正常加载。网络访问出现问题时，检查当前网络、浏览器扩展和学校提供的网络服务，再重新打开页面。

Kaggle 可以使用平台当前提供的注册方式创建账户。使用个人长期邮箱更便于持续维护；学校邮箱可能在毕业后停止使用。注册页面出现验证码或身份验证时，按照页面当前提示完成。

账户准备完成的判断

能够登录个人主页、打开公开 Notebook，并看到复制或编辑入口即可继续。

复制与运行 Notebook

  1. 从项目页进入公开 Notebook。
    核对标题、项目编号和任务内容。
  2. 复制到个人账户。
    使用页面当前提供的复制、编辑或保存副本入口，后续修改都在个人副本中完成。
  3. 从顶部依次运行。
    先运行环境、导入和数据单元格，再进入模型与评价。出现变量不存在时，检查上游单元格是否已经执行。
  4. 完成留出的任务。
    题目版会保留待填写代码或文字。完成后运行当前单元格并观察输出。
  5. 保存版本。
    完成一次完整运行后保存版本，保留代码、图像和指标。

计算资源

普通文件检查、表格分析和轻量模型可以使用 CPU。深度学习项目需要加速时，在 Notebook 设置中选择账户当前可用的 GPU 或其他加速器。平台提供的型号、额度和验证要求可能调整，因此本页不写固定型号和使用时长。

显存不足时可以减小 batch size、图像尺寸或模型规模，也可以重启会话释放显存。训练前先输出设备名称和关键数据 shape。

常见问题

找不到文件

检查数据是否已经添加、文件路径是否正确、大小写和目录层级是否一致。

变量不存在

运行依赖它的上游单元格；状态混乱时重启会话并从头运行。

库无法导入

确认库名、当前环境和安装单元格。项目已经准备环境时不要随意替换大型依赖。

运行速度很慢

确认代码是否使用预期设备，减少数据规模完成调试，再恢复正式设置。

本地环境入口

准备长期学习时，可以配置 Python 3.13、虚拟环境、VS Code 和 Jupyter。深度学习、医学影像或空间组学项目可能需要专门的 CUDA 与依赖版本，先阅读仓库的 README 和环境文件。

自学任务

打开一个公开 Notebook，复制到个人账户，从头运行全部单元格，记录一次数据 shape、一次模型输出和一项评价指标。这项任务用于自学和检查理解，不需要提交。
