加入 KYDW 后，先以预备成员身份完成科研基础训练和综合项目。通过考核后成为正式成员，可以选择剑桥课题组、合作课题组，也可以保持自由成员身份，自行参加其他团队的项目。论文署名、核心成员身份和个人项目安排与科研能力、项目参与和实际贡献有关。

1. 培养阶段

新成员先完成科研基础训练和综合项目考核，通过后成为正式成员，再根据兴趣和能力选择科研路径。

  1. 考察期预备成员

    学习 AI、生物医学、工程学、文献检索与阅读、信息梳理、编程等基础科研技能，并完成综合项目。

  2. 产出与考核根据综合表现进入正式成员阶段

    完成项目成果展示。希望加入剑桥课题组的成员还需要进行汇报。

  3. 正式加入KYDW 正式成员

    参与正常科研活动，并选择剑桥课题组、合作课题组或自由参与其他团队。

2. 考察与正式加入

2.1 考察期

考察期身份为预备成员。学习内容包括人工智能、生物医学、工程学、文献检索与阅读、资料梳理、编程和基本科研表达，并通过综合项目练习这些技能。

综合项目包括资料获取、研究问题理解、代码或实验执行、结果整理和汇报。考察时主要看学习进度、任务完成情况、问题处理和表达质量。

2.2 产出与考核

考察期结束后完成项目成果展示。计划加入剑桥课题组的成员还需要进行汇报。综合表现达到要求后进入 KYDW 正式成员阶段。

成果展示需要说明研究对象、使用的数据、采用的方法、得到的结果，以及这些结果支持的结论。

2.3 正式加入 KYDW

正式加入后，可以参与组内科研活动。尚未加入固定课题组的成员，可以自行联系和加入其他课题组，没有额外的组队限制。

4. 科研路径

正式成员可以根据研究兴趣、已有能力、合作机会和个人发展计划选择以下路径，也可以通过合作项目调整所属课题组。

路径适合的参与方式身份与特点
A 剑桥课题组方向参与剑桥课题组团队主线，同时根据个人表现进入 A1、A2、A3 等个人主线。进入后为剑桥课题组普通成员，同时获得慧医智心成员身份。
B 合作课题组方向按照合作课题组安排参与论文、项目或其他研究工作。进入后为合作课题组核心成员。是否加入慧医智心由对应课题组安排。
C 自行选择自主参与其他课题组的竞赛、论文等项目。保留 KYDW 成员身份。支持力度结合成员在 KYDW 事务中的参与度与贡献确定。

4.1 B 路径 合作课题组方向

进入合作课题组后，按照该组的研究方向和项目安排参与论文、项目或其他研究工作。

积累一定能力和经验后，希望加入剑桥课题组的成员，可以先以合作者身份参与剑桥课题组项目。后续根据实际表现、合作情况和项目需要，转为正式成员或核心成员。

4.2 C 路径 自行选择

未进入固定课题组的成员，可以自主参与其他课题组的竞赛、论文等项目。KYDW 根据成员在团队事务中的参与度和贡献提供支持。成员也可以通过合作项目加入剑桥课题组或合作课题组。

5. 剑桥课题组方向

剑桥方向包括团队主线和个人主线，两者可以并行开展。成员通常先参与团队项目，再根据表现、兴趣和能力承担个人课题。

5.1 团队主线

  • 参与组内正在推进的大论文项目。
  • 研究目标面向 Nature、Cell、Science 正刊及子刊等高水平成果方向。
  • 在完成分工任务的过程中积累技术能力、领域知识和科研经验。
  • 根据表现、兴趣和潜力，获得大论文作者署名机会以及后续个人培养计划。

团队主线通常周期较长，协作人数较多。新成员先承担具体的分工任务，熟悉数据、方法、实验和汇报，再逐步扩大负责的工作范围。

5.2 A1 高潜力成员加速培养

A1 面向考察阶段和团队主线项目中表现优异的成员，可破格获得核心成员身份。

  • 根据个人能力、研究兴趣和未来发展规划，定制第一作者论文项目。
  • 论文目标不低于 SCI 一区 Top 或 CCF A 类会议。
  • 根据负责人安排承担 KYDW 团队管理任务，并作为后续负责人候选者进行培养。

5.3 A2 常规成员培养

A2 面向参与积极、有研究想法、独立科研能力仍在快速成长阶段的成员，训练内容包括一次论文项目的选题、实验、写作、修改和投稿。

  • 鼓励组队投稿 MICCAI（International Conference on Medical Image Computing and Computer Assisted Intervention，CCF B 类国际顶级医学影像会议）。
  • 可以投稿课题组在 MICCAI 中承办的 Workshop CMMCA。
  • A2 项目中的论文第一作者由学生小队成员担任。

5.4 A3 合作培养

团队不定期与合作课题组开展论文项目合作。A3 面向除 A1 计划成员以外的所有成员开放，可以自由组队。

  • 人员可以从合作组加入剑桥方向，也可以从剑桥方向参与合作组项目。
  • 项目中可以获得合作课题组导师和 KYDW 在对应课题组内高年级成员的协助。
  • 作者次序按照项目约定和实际科研贡献确定。

6. 核心成员与慧医智心支持

6.1 核心成员

高潜力成员可以通过 A1 破格获得核心成员身份，其他成员可以通过论文成果达到以下晋级要求。

以主要作者身份完成任意一篇 SCI / CCF 论文，原则上至少满足以下条件之一：

  • SCI 新锐2区第一作者，包含共同第一作者中的第二位。
  • CCF C 类论文第一作者，不包含共同第一作者中的第二位。

如为正刊 / 子刊，则无需考虑作者名次。达到相应要求后，可获得 KYDW 团队核心成员身份。

核心成员在科研论文方面获得与 A1 相同的个人化支持。团队结合个人能力、研究兴趣和发展规划定制第一作者论文项目，目标不低于 SCI 一区 Top 或 CCF A 类会议，也包括 CCF B 类的 MICCAI。优异成员在升学阶段可根据实际合作情况，获得剑桥方面的推荐信或导师个人引荐支持。

6.2 慧医智心支持

进入剑桥课题组方向后，同时获得慧医智心成员身份，可获得本科阶段的项目组织、竞赛和综合成果支持。

支持类型内容
本科项目与竞赛大创、竞赛以及相关项目的组织和推进。
成果形式软件著作权、专利及其他适合本科阶段的成果形式。
校内发展补充本科阶段校内加分与保研 / 申研所需的综合条件。
资源协调项目组织、队伍对接、资源协调与执行支持。

7. 期刊与会议

科研成果包括期刊论文和会议论文。医学、生命科学和工程领域较常使用期刊评价体系，计算机和人工智能领域也重视高水平学术会议。期刊分区与会议分级采用不同的评价方式，不能按数字直接换算。

术语基本含义在培养体系中的位置
期刊论文投稿到学术期刊，经过同行评审、修改后正式发表。医学、生物医学工程和多数自然科学方向常以期刊为主要成果形式。团队主线和个人项目都可能形成期刊论文。
会议论文投稿到学术会议，经评审后录用并在会议中发表或展示。计算机和人工智能领域的高水平会议具有很高学术认可度。A1 会关注 CCF A 类会议，A2 会重点接触 MICCAI。
SCI日常科研语境中常用来描述 Web of Science 核心体系中的自然科学、工程和医学期刊论文。核心成员晋级和个人论文目标中都会出现。
一区 / 二区常见期刊分区表达。实际使用中可能涉及 JCR 分区或中科院分区，具体项目会明确采用的口径。A1 和核心成员个人项目使用 SCI 一区 Top 作为高水平目标。
Top 期刊某个领域中认可度和影响力较高的一批期刊。不同学科的 Top 范围不同。SCI 一区 Top 表示较高水平的期刊目标。
CCF A / B / C中国计算机学会推荐目录中的分级。A、B、C 表示不同推荐层次，A 级层次最高。A1 目标包括 CCF A。核心成员口径中也使用 CCF 等级。
MICCAI医学影像计算与计算机辅助干预领域的国际会议，属于 CCF B 类，是医学影像领域的顶级学术会议。A2 组队论文的重要投稿目标。
Workshop针对特定研究主题组织的专题研讨会。CMMCA 属于这一类，适合 A2 成员进行完整论文训练。

7.1 Nature、Cell、Science 正刊及子刊

Nature、Cell、Science 正刊及子刊是团队主线的长期研究目标。正刊指对应主刊，子刊指同一出版体系中的系列期刊。各子刊的学科方向和学术影响力不同，项目根据研究问题选择投稿期刊。

这类项目通常周期较长，参与人数较多。成员按分工完成研究工作，作者位置依据实际贡献确定。

8. 论文署名

论文作者顺序反映研究中的主要贡献和责任。KYDW 项目结合项目约定和实际贡献确定作者顺序。

概念含义
第一作者 一作通常承担论文中最主要的研究工作之一，包括研究设计、实验、结果整理和论文写作。个人论文项目以培养成员独立承担第一作者工作为目标。
共同第一作者 共一多名作者被标注为同等贡献。共一第二表示作者列表中排在第二位，同时被声明为共同第一作者。
主要作者在项目中承担实质性的核心研究工作。核心成员晋级使用主要作者身份作为重要条件。
论文作者署名成员完成相应科研贡献后进入作者列表，具体位置结合项目约定和实际贡献确定。
作者顺序通常越靠前代表承担的核心工作越多。合作项目会在项目开始或推进过程中明确作者排序原则，并根据最终实际贡献调整。

8.1 核心成员的作者位置要求

核心成员晋级时，SCI 新锐2区第一作者包含共一第二，CCF C 类第一作者不包含共一第二。正刊 / 子刊论文不限制作者名次。

核心成员晋级用于 KYDW 内部培养和项目安排。论文投稿仍需经过期刊或会议的同行评审。

9. 进入项目后的学习顺序

前期先完成考察项目，熟悉科研工作的基本方法；参与项目后，逐步承担独立的研究任务。

第一阶段：完成考察项目

熟悉资料检索、论文阅读、代码或实验执行、结果整理和汇报。完成综合项目，并能清楚解释方法和结果。

第二阶段：项目执行与记录

按时推进任务，保留实验记录，及时汇报问题，整理代码与数据，确认结果可以复现。

第三阶段：研究兴趣与技术方向

接触医学影像、病理、组学、算法、生物信息、工程实现等方向，结合兴趣选择研究问题。

第四阶段：独立负责研究问题

能够独立查文献、提出方案、完成实验、解释结果和组织写作后，可以承担更独立的一作项目，或进入 A1、核心成员培养。

10. 长期协作

KYDW 成员自愿参与科研与团队事务。获得信息、资源和指导支持的同时，也承担相应的责任与义务。

刚加入时，可以向团队和高年级成员学习。积累经验后，参与经验分享、资料整理和新成员指导，也可以介绍合适的资源与合作机会。成员之间的合作可以延续到后续的学术研究与工业界工作。
