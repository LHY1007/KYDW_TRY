- 体验教学：`experience/teaching/`

- 进阶教学、进阶实践、进阶实践项目参考答案、设计报告模板、参考设计报告和进阶项目通用资料：当前均在仓库外的本地内部归档，不进入 GitHub Pages。

## 三、体验版与进阶版的职责

- 体验版：先阅读基础教学内容，再在 Notebook 中完成和补全指定代码或文字，最后使用实践项目参考答案核对。体验版不要求提交报告。
- 进阶版：继续学习同一方向的方法、验证设计和前沿研究；学生需要自行设计或选择方法，完成实践并提交设计报告，在报告中解释方法选择、验证设计和结果判断。

总览页、周页面和项目详情页都从 `content.js` 读取这两层说明。修改学习要求时必须同时检查三处实际渲染结果，但不要在页面模板中另写第二份项目规则。

## 四、导入与替换

运行：

```powershell
python tools\import_experience_materials.py `
  --source "D:\00_同步\BaiduSyncdisk\01_学术研究\学生\KYDW\网站内容" `
  --repo .
```

导入脚本负责：

1. 保留原始材料，向网站目录复制并规范文件名。
2. 为教学页和体验解析页增加“返回项目详情”。
3. 在进阶项目明确开放后，才生成设计报告和通用资料的网页阅读版；当前这些文件保存在本地内部归档。
4. 删除旧的体验版临时进阶副本，避免项目 00 出现进阶入口。
5. 生成 `content/advanced-manifest.md`，记录来源文件哈希和进阶教学本地配图状态。

## 五、每次更新必须检查

1. 标题、项目编号、任务对象和实践内容是否在教学、Notebook、答案和设计报告之间一致。
2. 项目 00 是否只显示一层；项目 01—05 是否显示体验版和进阶版。
3. 体验版实践是否以完成指定内容为主；进阶版是否明确要求方法设计、报告和方法选择解释。
4. 每个教学页、解析页、报告页能否返回对应项目详情。
5. Notebook 链接是否下载正确文件，报告模板与参考报告是否进入对应项目。
6. 教学文档库是否只出现已开放项目的体验教学入口；进阶教学、进阶实践项目参考答案和报告材料当前不进入公开仓库，也不得生成可点击入口。
7. 首页、项目总览、Week 页面和项目详情是否使用相同标题、编号与开放状态。
8. 不把当前已上传数量写成项目总数；后续材料继续追加到同一目录和数据结构。
