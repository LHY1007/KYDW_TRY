# 本科生科研入门体验项目

大家好，KYDW 暑期本科生科研入门体验项目现已开放。项目面向没有科研经历的本科生，线上自学即可完成，不需要硬件或湿实验条件。

目前开放 Week 1，内容包括：

- 基础编程与人工智能
- MRI 肿瘤图像分割
- 胸部 X 射线与生成模型

每个项目都包含教学项目、实践项目和实践项目参考答案。网页可直接阅读，实际代码实践使用 Kaggle；体验项目完成指定内容即可，不要求提交报告。

Week 2 及之后的体验项目、所有进阶项目目前保持锁定。项目目录会继续加入新的研究主题，开放后即可从项目主页进入。
