实践项目参考答案 05：空间转录组表达超分辨率

使用配对 H&E、16 μm Snap25 输入和 2 μm 参考表达图，训练轻量融合模型并与插值基线比较。

参考答案仅做参考，并非代表唯一正确结果，效果以运行结果为准，具体代码形式可自行调整。打开公开 Kaggle Notebook 后，先复制到自己的账户，再修改题目中标记的区域并运行。

读取配对数据

只读取固定文件名，并检查 he、lr、hr 和 split 四个字段。

candidates = sorted(Path('/kaggle/input').rglob('kydw-try-a05-paired-patches.npz'))
assert candidates, '请挂载课程数据集。'
data = np.load(candidates[0], allow_pickle=True)
he = data['he'].astype(np.float32) / 255.0
lr = data['lr'].astype(np.float32)
hr = data['hr'].astype(np.float32)
split = data['split'].astype(str)

输入与目标

LR 粗尺度总量除以 64 后作为细网格密度基线，H&E 与表达通道拼接。

lr_total = lr[i]
lr_density = lr_total / 64.0
x = np.concatenate([he[i], np.log1p(lr_density)], axis=0)
y = np.log1p(hr[i])

轻量联合输入模型

三个 H&E 通道与一个表达通道共同进入卷积网络。

self.body = nn.Sequential(
    nn.Conv2d(4, 16, 3, padding=1), nn.ReLU(),
    nn.Conv2d(16, 16, 3, padding=1), nn.ReLU(),
    nn.Conv2d(16, 1, 3, padding=1),
)

def forward(self, x):
    return torch.nn.functional.softplus(x[:, 3:4] + self.body(x))

聚合一致性

高分辨率预测按 8×8 区域求和后与低分辨率总量比较。

def aggregate8(x):
    return torch.nn.functional.avg_pool2d(x, 8, 8) * 64

pred = torch.expm1(pred_log).clamp_min(0)
lr_total_coarse = torch.nn.functional.avg_pool2d(lr_raw, 8, 8)
consistency = (aggregate8(pred) - lr_total_coarse).abs().mean()
loss = (pred_log - target_log).abs().mean() + .1 * consistency

模型与插值比较

同一测试区域使用相同色标，比较 MAE、相关性和误差图。

mae_model = np.abs(pred - target).mean()
mae_baseline = np.abs(baseline - target).mean()
pearson = np.corrcoef(pred.ravel(), target.ravel())[0, 1]
vmax = np.percentile(target, 99)

本次参考结果

插值基线测试 MAE 为 0.199，轻量模型测试 MAE 为 0.184，模型与 2 μm 参考表达图的像素相关性为 0.117。MAE 略有下降但相关性仍低，当前结果不能解释为已恢复可靠的细尺度表达结构。
