任务 2：Dice 计算

Dice 用预测前景与真实前景的重叠程度评价分割结果。prob 是模型经过 sigmoid 后的概率图，target 是 0/1 mask；概率大于等于 threshold 的像素属于预测前景。

本单元格说明： 在 dice_score 的参考代码段中完成阈值化、交集、预测面积和真实面积的计算，并返回 batch 内样本 Dice 的平均值。

输入与输出： prob、target 和 pred 的 shape 都是 [batch, 1, H, W]；沿空间维度求和后，每个样本得到一个 Dice，函数最后输出一个标量。

检查： 使用给定的 threshold、eps 和空间维度；soft_dice_score 已提供给训练损失使用。后面的训练应能得到有限的 Dice。

代码单元格12
def dice_score(prob,target,threshold=.5,eps=1e-6):  # 定义可重复调用的计算步骤
    # 参考实现：阈值化、计算交集与两侧面积
    pred = (prob >= threshold).float()  # 计算模型输出或预测概率
    dims = tuple(range(1, pred.ndim))  # 保存当前步骤使用的中间结果
    intersection = (pred * target).sum(dims)  # 保存当前步骤使用的中间结果
    denominator = pred.sum(dims) + target.sum(dims)  # 保存当前步骤使用的中间结果
    return ((2 * intersection + eps) / (denominator + eps)).mean()  # 返回当前步骤的计算结果

def soft_dice_score(prob,target,eps=1e-6):  # 定义可重复调用的计算步骤
    dims=tuple(range(1,prob.ndim))  # 计算模型输出或预测概率
    inter=(prob*target).sum(dims)  # 计算模型输出或预测概率
    return (2*inter+eps)/(prob.sum(dims)+target.sum(dims)+eps)  # 返回当前步骤的计算结果

任务 3：U-Net 卷积块

DoubleConv 是 U-Net 中重复使用的小模块：两次 3×3 卷积，每次卷积后进行归一化和 ReLU。padding=1 让高度和宽度保持不变，便于后面与跳跃连接拼接。

本单元格说明： 用 cin、cout 构造 self.block，顺序为卷积、归一化、ReLU、卷积、归一化、ReLU。不要改动 TinyUNet 中已经给出的连接。

输入与输出： 输入是 [batch, cin, H, W]，输出是 [batch, cout, H, W]。各层的 cin、cout 已由 TinyUNet 给出。

检查： 运行模型构造代码并查看参数量；后续前向传播的通道维度应能顺利连接。

代码单元格14
class DoubleConv(nn.Module):  # 定义本任务使用的模型或数据结构
    def __init__(self,cin,cout):  # 定义可重复调用的计算步骤
        super().__init__()  # 执行当前计算步骤
        # 参考实现：
        self.block = nn.Sequential(  # 保存当前步骤的中间结果
            nn.Conv2d(cin, cout, 3, padding=1, bias=False),  # 保存当前步骤的中间结果
            nn.GroupNorm(8, cout),  # 执行当前计算步骤
            nn.ReLU(inplace=True),  # 保存当前步骤的中间结果
            nn.Conv2d(cout, cout, 3, padding=1, bias=False),  # 保存当前步骤的中间结果
            nn.GroupNorm(8, cout),  # 执行当前计算步骤
            nn.ReLU(inplace=True),  # 保存当前步骤的中间结果
        )  # 保存当前步骤使用的中间结果
    def forward(self,x): return self.block(x)  # 定义可重复调用的计算步骤

class TinyUNet(nn.Module):  # 定义本任务使用的模型或数据结构
    def __init__(self):  # 定义可重复调用的计算步骤
        super().__init__()  # 执行当前计算步骤
        self.e1=DoubleConv(1,16); self.p1=nn.MaxPool2d(2)  # 保存当前步骤使用的中间结果
        self.e2=DoubleConv(16,32); self.p2=nn.MaxPool2d(2)  # 保存当前步骤使用的中间结果
        self.b=DoubleConv(32,64)  # 保存当前步骤使用的中间结果
        self.u2=nn.ConvTranspose2d(64,32,2,2); self.d2=DoubleConv(64,32)  # 保存当前步骤使用的中间结果
        self.u1=nn.ConvTranspose2d(32,16,2,2); self.d1=DoubleConv(32,16)  # 保存当前步骤使用的中间结果
        self.out=nn.Conv2d(16,1,1)  # 建立用于比较的模型
    def forward(self,x):  # 定义可重复调用的计算步骤
        e1=self.e1(x); e2=self.e2(self.p1(e1)); b=self.b(self.p2(e2))  # 保存当前步骤使用的中间结果
        d2=self.d2(torch.cat([self.u2(b),e2],1))  # 保存当前步骤使用的中间结果
        d1=self.d1(torch.cat([self.u1(d2),e1],1))  # 保存当前步骤使用的中间结果
        return self.out(d1)  # 返回当前步骤的计算结果

def run_epoch(loader,training):  # 定义可重复调用的计算步骤

本单元格说明： 在参考代码段遍历验证集，计算三个候选阈值对应的 val_dices，并从给定列表中选出 best_threshold。测试集不能参与阈值选择。

输入与输出： 输入是最佳模型、val_loader 和候选阈值；输出是阈值到 Dice 的字典和一个候选浮点数。后面的完整 evaluate 函数会返回测试 Dice、IoU、预测样本和空 mask 统计。

检查： 所有候选阈值都应有数值，best_threshold 必须属于代码中给定的列表。

# 输入：model、val_loader 和候选 thresholds；输出：val_dices、best_threshold。
thresholds = [.3, .5, .7]  # 保存当前步骤使用的中间结果
val_dices = {}  # 计算用于比较的评价指标

# 下面的 evaluate 已经完整提供；本任务只补全阈值遍历和最佳阈值选择。
def evaluate(loader, threshold):  # 定义可重复调用的计算步骤
    model.eval(); ds=[]; ious=[]; positive_ds=[]; positive_ious=[]; examples=[]  # 保存当前步骤使用的中间结果
    empty_true=empty_pred=both_empty=0  # 保存当前步骤使用的中间结果
    with torch.no_grad():  # 在受控上下文中读取或计算
        for x,y,pid in loader:  # 逐批或逐样本执行当前步骤
            prob=torch.sigmoid(model(x.to(DEVICE))).cpu(); pred=(prob>=threshold).float()  # 计算模型输出或预测概率
            target_area=y.sum((1,2,3)); pred_area=pred.sum((1,2,3))  # 保存当前步骤使用的中间结果
            empty_true += int((target_area==0).sum()); empty_pred += int((pred_area==0).sum())  # 保存当前步骤使用的中间结果
            both_empty += int(((target_area==0)&(pred_area==0)).sum())  # 保存当前步骤使用的中间结果
            inter=(pred*y).sum((1,2,3)); union=((pred+y)>0).float().sum((1,2,3))  # 保存当前步骤使用的中间结果
            d=(2*inter+1e-6)/(pred.sum((1,2,3))+y.sum((1,2,3))+1e-6)  # 保存当前步骤使用的中间结果
            i=(inter+1e-6)/(union+1e-6)  # 保存当前步骤使用的中间结果
            positive=target_area>0  # 保存当前步骤使用的中间结果
            ds.extend(d.numpy()); ious.extend(i.numpy()); positive_ds.extend(d[positive].numpy()); positive_ious.extend(i[positive].numpy())  # 执行当前计算步骤
            if len(examples)<4:  # 根据当前条件选择处理分支
                for k in range(min(4-len(examples),len(x))): examples.append((x[k,0].numpy(),y[k,0].numpy(),prob[k,0].numpy()))  # 逐批或逐样本执行当前步骤
    stats={'total':len(ds),'empty_true':empty_true,'empty_pred':empty_pred,'both_empty':both_empty,'positive_true':len(positive_ds),'positive_dice':float(np.mean(positive_ds)) if positive_ds else None,'positive_iou':float(np.mean(positive_ious)) if positive_ious else None}  # 计算用于比较的评价指标
    return float(np.mean(ds)),float(np.mean(ious)),examples,stats  # 返回当前步骤的计算结果
# 参考实现：遍历验证集，计算每个 threshold 的 Dice。
# 参考实现：从 val_dices 中选择验证 Dice 最高的候选阈值。
for threshold in thresholds:  # 逐批或逐样本执行当前步骤
    _, _, _, stats = evaluate(val_loader, threshold)  # 保存当前步骤使用的中间结果
    score = stats['positive_dice'] if stats['positive_dice'] is not None else 0.0  # 计算用于比较的评价指标
    val_dices[threshold] = float(score)  # 计算用于比较的评价指标
best_threshold = max(val_dices, key=val_dices.get)  # 计算用于比较的评价指标
