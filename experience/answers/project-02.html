步骤 3/7

Dice 函数同时支持训练和评价

训练时使用概率图计算 soft Dice；评价时先用阈值把概率图变成二值预测。正样本 Dice 单独统计真实 mask 非空的切片，避免大量空 mask 把模型的空预测误读成高分。

参考答案

def dice_score(prob,target,threshold=.5,eps=1e-6):
    pred=(prob>=threshold).float()
    dims=tuple(range(1,pred.ndim))
    inter=(pred*target).sum(dims)
    return ((2*inter+eps)/(pred.sum(dims)+target.sum(dims)+eps)).mean()

def soft_dice_score(prob,target,eps=1e-6):
    dims=tuple(range(1,prob.ndim))
    inter=(prob*target).sum(dims)
    return (2*inter+eps)/(prob.sum(dims)+target.sum(dims)+eps)

U-Net 卷积块提取局部和整体特征

编码器逐步压缩空间尺寸并扩大通道数，解码器用转置卷积恢复分辨率；跳跃连接把浅层的边界信息传给解码器。每个卷积块执行两次卷积、归一化和 ReLU。

步骤 5/7

训练更新同时照顾像素分类和区域重叠

BCEWithLogitsLoss 约束每个像素，soft Dice 直接约束预测区域与真实区域的重叠。正/空 mask 平衡采样，配合正类权重，减少模型只输出空 mask 的倾向。

参考答案

bce=nn.BCEWithLogitsLoss(pos_weight=torch.tensor([5.0],device=DEVICE))
opt=torch.optim.AdamW(model.parameters(),lr=1e-3,weight_decay=1e-4)

阈值只用验证集选择
