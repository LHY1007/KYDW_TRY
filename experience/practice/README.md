# 体验实践项目

这里保存已登记项目的体验版实践 Notebook。进阶项目当前不公开，相关材料不放在 GitHub Pages；用户明确开放后，再从本地内部归档恢复并登记对应入口。

## Kaggle 实践方式

每个项目都优先通过对应的 Kaggle Notebook 完成。打开公开 Notebook 后，点击“复制并编辑”保存到自己的 Kaggle 账户，再逐步运行、修改代码并观察自己的输出；下载 Notebook 到电脑运行是补充方式。完全不熟悉代码时，可以把当前单元格交给 AI，逐步询问代码作用、报错原因和下一步修改，再用实践项目参考答案核对结果。

网页中的“实际参考输出”来自对应实践项目参考答案中已经保存的结果图或 Notebook 输出。网页按钮不会替代 Kaggle 的真实运行；自己的数据、参数和修改结果应以 Kaggle 账户中的实际运行结果为准。
