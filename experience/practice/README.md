# 体验实践项目

这里保存已登记项目的实践 Notebook。网站项目页可以把这些 Notebook 作为体验项目和暂代的进阶项目入口；进阶版本的代码材料完成后，只需在 `content.js` 中替换对应的 `advancedPractice` 路径。

## 项目对应关系

| 网站项目 | 原材料编号 | Notebook | 解析页 |
| --- | --- | --- | --- |
| 01 基础编程与人工智能 | 00 | `project-01.ipynb` | `../answers/project-01.html` |
| 02 MRI 肿瘤图像分割 | 01 | `project-02.ipynb` | `../answers/project-02.html` |
| 03 胸部 X 射线与生成模型 | 02 | `project-03.ipynb` | `../answers/project-03.html` |
| 04 计算病理与脑膜瘤形态分析 | 03 | `project-04.ipynb` | `../answers/project-04.html` |
| 05 脑疾病表格数据与 XGBoost 预测 | 04 | `project-05.ipynb` | `../answers/project-05.html` |
| 06 空间转录组与表达超分辨率 | 05 | `project-06.ipynb` | `../answers/project-06.html` |

实践 Notebook 中保留学生需要完成的代码位置；参考实现只放在对应解析页。部署前按本目录中的“实践项目额外注意事项”检查数据路径、字段名、划分方式和输出文件名。
