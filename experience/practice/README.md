# 实践项目材料

这里保存项目 00—05 的实践 Notebook。每个 Notebook 都保留需要完成的代码位置，网页中的参考输出与对应的实践参考答案保持一致。

## Kaggle 实践方式

每个项目都优先通过对应的 Kaggle Notebook 完成。打开公开 Notebook 后，点击“复制并编辑”保存到自己的 Kaggle 账户，再逐步运行、修改代码并观察自己的输出；下载 Notebook 到电脑运行是补充方式。遇到不理解的代码时，先结合单元格说明、变量名和公开资料阅读，再用实践参考答案核对结果。

网页中的“参考输出”来自对应实践参考答案中保存的结果图或 Notebook 输出。自己的数据、参数和修改结果应以 Kaggle 账户中的输出为准。
