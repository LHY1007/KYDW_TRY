项目 04 参考设计报告：受试者级验证、校准与决策价值

本报告对应逻辑回归参考答案。它重点展示验证设计，而不是把小型 UCI 数据包装为临床诊断系统。其他模型可以成立，但必须使用相同受试者级折。

1. 研究问题

输入是语音信号计算得到的生物医学特征，输出是帕金森状态概率。核心问题是同一受试者多次录音造成的相关性如何影响评价，以及模型在新受试者上是否仍具有区分度和合理概率。

2. 数据与 ID 解析

UCI 数据包含 31 名受试者和 195 条记录。name 形如 phon_R01_S01_1，最后一段是录音编号，删除它才得到受试者 ID。若只取第一个下划线字段，会把所有记录错误归为 phon，完全破坏分组。代码检查每个受试者的 status 唯一。

3. 两种验证的含义

按记录的 StratifiedKFold 允许同一受试者进入不同折，测试模型是否识别见过的人或录音条件；它是有意设置的乐观对照。StratifiedGroupKFold 保证受试者不跨折，同时尽量维持类别比例，主结果由其 out-of-fold 概率产生。所有填补、标准化和模型拟合都在 Pipeline 内部完成。

4. 模型与方法选择

逻辑回归参数少、概率形式清楚、便于校准和检查系数，适合 31 名受试者。XGBoost 可表达非线性，但有效样本量是受试者数而不是 195 行，更容易过拟合。复杂模型应在相同折中比较，并使用嵌套验证选择超参数。

5. 评价

ROC-AUC 衡量任意阳性/阴性对的排序；AUPRC 更受阳性比例影响，关注阳性预测；Brier 衡量概率误差。校准曲线比较分箱概率和真实频率。决策曲线把阈值对应的假阳性代价纳入净收益，但本数据没有真实临床流程，因此只能示范计算。

参考代码使用全体 out-of-fold 概率，避免单次小测试集偶然性。仍应通过 bootstrap 或重复分组交叉验证估计不确定性。31 名受试者不足以稳定评价复杂模型、校准曲线或决策曲线。

6. 阈值

0.5 只是演示阈值。真实阈值取决于模型用途：若用于进一步无创筛查，可能容忍较多假阳性以减少漏诊；若后续检查昂贵或有风险，阈值可能更高。阈值不能仅根据测试集最大 F1 选择后再在同一测试集报告。

7. 结果解释

若记录级 AUC 明显高于受试者级 AUC，说明模型利用了个体重复信息。若 AUC 尚可但 Brier 或校准较差，模型可以排序却不能把数值当作风险概率。若决策曲线只在很窄阈值范围优于 treat-all/none，需要谨慎解释。

8. 局限、适用性与偏倚

数据人群、设备、语音任务和疾病谱有限；健康与患者比例不代表筛查人群；同一受试者多次录音；没有外部中心；特征可能受麦克风和环境影响。该结果不能直接声称临床诊断性能。TRIPOD+AI 和 PROBAST+AI 提醒研究者报告数据来源、缺失、样本量、验证、性能和适用性。

9. 下一步实验

优先重复受试者级交叉验证并给出置信区间；比较逻辑回归与受限树模型；检查中心/设备或录音条件；在独立队列外部验证；若用于随访，重新定义纵向预测问题而不是当前状态分类。

10. AI/Agent 使用范例

Agent 可帮助解析 ID、构造 Pipeline、解释指标和审查泄漏。人工必须验证每折受试者交集、特征选择位置、校准实现和临床阈值含义。

11. 本包可运行性验证记录

在没有联网下载 UCI 文件的自动验证环境中，参考答案使用保留 31 名受试者和重复录音结构的 demo 数据。记录级 ROC-AUC 为 0.991，受试者级 ROC-AUC 为 0.971；受试者级 Brier 为 0.065。演示结果刻意让同一人的重复记录相似，因此记录级评价更乐观，用于展示泄漏风险。它不代表 UCI 数据或真实临床性能。挂载官方数据后，应重新核对 31 名受试者、195 条记录、每名受试者标签一致性，并在报告中替换全部指标和图。

12. 设计报告提交检查

报告必须说明预测时点、目标人群和用途；解释受试者 ID 的解析；比较记录级与受试者级验证的含义；说明预处理为何放在 Pipeline；解释模型复杂度与有效样本量；分别报告区分度、概率质量和阈值结果；讨论决策曲线的阈值范围和假阳性代价；列出数据代表性、外部验证和临床工作流限制。性能高不能替代这些说明。

13. 失败分析与替代方案

记录级与受试者级结果接近，并不自动说明没有泄漏，还应检查同一家庭、设备、中心或采集日期是否跨折。AUC 较高但校准较差时，可以比较正则化强度、Platt scaling 或 isotonic calibration；校准器必须在训练内部拟合。若不同折波动很大，应报告受试者数、每折类别构成和置信区间，而不是只给平均值。

替代模型可包括受限深度的树、XGBoost、随机森林和非线性核方法。有效样本量接近受试者数，复杂模型需要嵌套验证和严格正则化。若研究目标是未来进展而不是当前状态，整个问题需要改为纵向或生存预测，不能只替换分类器。

14. 复现产物与核对方式

参考 Notebook 生成记录级与受试者级评价、校准图、决策曲线和 JSON 指标。真实数据运行后应保存受试者 ID 解析表、每折受试者清单、Pipeline 配置、out-of-fold 概率和阈值混淆矩阵。报告中的每个性能数值都应能追溯到明确的划分和预测文件。
