1. 为一张图添加批次维度

题目：构造[3,8,8]的浮点RGB张量，添加批次维度并恢复原形状。解释为什么不能随意把通道维度当成批次。

import torch
x = torch.zeros(3, 8, 8)
batch = x.unsqueeze(0)
restored = batch.squeeze(0)
assert batch.shape == (1, 3, 8, 8)
assert torch.equal(x, restored)

unsqueeze(0)只增加一个长度为1的轴，没有新增图像信息。批次代表多个样本，通道代表同一图像不同颜色分量。

2. 计算一次分类决策

题目：两个样本对三个类别的分数分别为[1,3,0]与[4,2,1]。预测类别是什么？若标签为1和2，准确率是多少？

scores = torch.tensor([[1., 3., 0.], [4., 2., 1.]])
labels = torch.tensor([1, 2])
prediction = scores.argmax(dim=1)
accuracy = (prediction == labels).float().mean()
assert prediction.tolist() == [1, 0]
assert accuracy.item() == 0.5

类别从0编号。dim=1表示在每一行的类别维上找最大值。第二个样本虽然有最高分，也可能预测错误。

3. 忽略边界再计算重叠

题目：参考为[[1,0],[255,1]]，预测为[[1,1],[1,0]]。忽略左下角后，TP、FP、FN分别是多少？

import numpy as np
reference = np.array([[1, 0], [255, 1]])
prediction = np.array([[1, 1], [1, 0]])
valid = reference != 255
p = prediction[valid] == 1
y = reference[valid] == 1
tp = np.logical_and(p, y).sum()
fp = np.logical_and(p, ~y).sum()
fn = np.logical_and(~p, y).sum()
dice = 2 * tp / (2 * tp + fp + fn)
assert (tp, fp, fn) == (1, 1, 1)
assert dice == 0.5

忽略规则在统计前执行。未确定边界不会因为预测为前景而自动计为假阳性。

4. 验证detach的作用

题目：x=2时，y=x*x对x的梯度是多少？换成x.detach()后，新的结果是否保留梯度路径？

x = torch.tensor(2., requires_grad=True)
y = x * x
y.backward()
assert x.grad.item() == 4.
z = x.detach() * x.detach()
assert not z.requires_grad

这个数值例子帮助理解判别器步骤为何把生成图detach。生成器更新步骤需要保留通向生成图的梯度路径。

5. 对齐图块后比较模型

题目：两张表的行顺序不同，能否直接相减？先按ID连接，再计算同图块差值。

import pandas as pd
l1 = pd.DataFrame({'pair_id':['A','B'], 'mae':[0.12,0.20]})
gan = pd.DataFrame({'pair_id':['B','A'], 'mae':[0.18,0.14]})
paired = l1.merge(gan, on='pair_id', suffixes=('_l1','_gan'), validate='one_to_one')
paired['delta'] = paired.mae_gan - paired.mae_l1
assert np.allclose(paired.delta, [0.02,-0.02])

平均差为0并不表示每个图块都没有变化。A变差，B改善；需要保留配对差值及样例。

6. 避免把缺失误差填成零

errors = np.array([0.10, np.nan, 0.20])
valid = np.isfinite(errors)
mean = errors[valid].mean()
assert valid.sum() == 2
assert np.isclose(mean, 0.15)

结果同时报告均值与有效数量。把NaN填成0后均值会变成0.10，含义错误。
