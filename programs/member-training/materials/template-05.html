把三个项目放进一份压缩包，命名为 KYDW_姓名_培训考核.zip。每个文件夹只放该项目的代码、主要结果和表达材料。

KYDW_姓名_培训考核.zip
├─ 01_猫狗识别/
│  ├─ 猫狗识别.ipynb
│  ├─ 结果/                    预测表、混淆矩阵和错误样例
│  ├─ 流程图与结果.pptx
│  └─ 流程图与结果.pdf
├─ 02_图像分割/
│  ├─ 图像分割.ipynb
│  ├─ 结果/                    分割对照图和逐图指标
│  ├─ 短报告.docx
│  └─ 短报告.pdf
└─ 03_图像翻译/
   ├─ 图像翻译.ipynb
   ├─ 结果/                    输入、参考、预测与逐图指标
   ├─ 学习海报.pptx
   └─ 学习海报.pdf

在本地写程序的同学，可将对应的 .ipynb 换成 .py 文件；有多个脚本时放进该项目的 代码 文件夹，并用简短的 运行说明.md 写明入口和数据来源。

结果只保留说明主要发现所需的表和图。图中的样本编号与代码输出对应，报告和海报中的数字也能在结果文件中找到。
