2. 猫狗识别

一张猫狗照片对应一个类别，模型的任务是给出猫和狗两个分数。学习本章时，先看清每一步的输入与输出，再完成一次计算和一次参数更新。你需要独立把数据读取、训练、验证和测试组织起来，并用自己画的流程图解释这些部分。

分类分数与预测类别

模型接收一批 RGB 张量，输出形状为 [批量大小,2] 的原始分数，通常称为 logits。两个分数中较大者决定预测类别。标签是 0 或 1，表示真实类别；它不是模型算出来的概率。

Softmax 可以把两个分数转成总和为 1 的数，便于观察模型的相对倾向。分数很高并不自动说明判断可靠，尤其在数据分布变化时。训练时，PyTorch 的交叉熵直接接收 logits 和整数标签，内部已经完成需要的变换，不要事先重复做 Softmax。

卷积、特征与分类头

卷积用较小的可学习权重观察局部像素，并在不同位置重复使用同一组权重。它能够学习与边缘、纹理或局部形态有关的计算。随着层数增加，后续计算组合更大范围的信息；不能仅根据某一层的名字就断言它学会了“猫耳朵”。

激活函数使模型能够表达非线性关系。池化或带步长的卷积降低空间尺寸，减少后续计算。最后，分类头把图像的特征汇总为两个分数。模型中间的“通道”已经是学习得到的特征通道，不再分别表示红、绿、蓝。

固定尺寸的展平分类器可以作为简单参照，卷积网络是另一种选择。若采用已有预训练模型，应记录权重来源、输入规范和哪些层参与训练，避免把预训练带来的知识差异误说成仅仅是网络结构差异。

损失、梯度与一次更新

损失描述当前预测与标签的差异。分类交叉熵会对真实类别分数过低的预测给予较大损失。自动求导计算各参数变化对损失的影响，优化器依据梯度更新参数。学习率控制每次更新的步幅。

一次更新包括取得一批数据、计算输出与损失、清空旧梯度、反向传播和更新参数。梯度默认会累积，所以清空梯度的位置需要明确。一次更新只能用于理解计算过程；它不等于已经得到可用的猫狗分类器。

训练、验证与测试

训练集用于计算梯度并更新参数。验证集用于比较设置、观察过拟合和选择检查点。测试集在方案确定后用于评价最终模型。反复根据测试分数调整参数，会让测试集逐渐参与方案选择。

使用 Oxford-IIIT Pet 时保留官方测试部分，从官方 trainval 部分划出自己的训练与验证集合，并保存具体文件名。猫狗两类都应在各集合中出现。数据增强只作用于训练数据；验证和测试的处理保持稳定。不要把同一张照片的不同裁剪分别放进训练与测试。

训练模式和评价模式也有区别。Dropout、BatchNorm 等层在两种模式下行为不同；评价时关闭梯度计算可以减少开销，但不会替你自动切换模型模式。重新启动环境后，能够加载保存的权重并得到相同的评价结果，是一次有效的保存检查。

分类指标与错误照片

准确率是正确预测数除以样本总数。若某一类明显更多，只看准确率可能忽略另一类的错误。混淆矩阵把真实类别与预测类别组合成四个格子，能直接看到猫被分成狗、狗被分成猫的数量。

固定“狗”为正类时，精确率描述预测为狗的照片里有多少确实是狗；召回率描述真实狗照片里有多少被找出来。更换正类后，这两个数字的含义也会改变。记录指标时写清类别约定，并保留逐张预测记录。

PPT 流程图与对象尺寸

先在纸上列出自己的计算对象：图像、预处理后的张量、模型、两个类别分数和预测类别。流程图中的框表示对象或操作，连接线表示数据或计算关系。训练所用标签和损失可以放在另一条支路，不要把真实标签画成模型预测时的输入。

在 PowerPoint 新建空白页，进入“设计 → 幻灯片大小 → 宽屏（16:9）”。在“插入 → 形状”放置一个矩形，再用“形状格式 → 大小”设置宽和高，例如宽 3.2 cm、高 1.4 cm。复制矩形时使用 Ctrl+D，可以保留大小、颜色与字体；它只是图形复制，框中的文字仍需对应实际计算。

选择多个框，使用“形状格式 → 对齐 → 顶端对齐”，再选择“横向分布”。使用分布前先确定最左和最右两个框的位置；对齐菜单中“对齐所选对象”与“对齐幻灯片”的参照不同。打开“视图 → 参考线/网格线”，可以让图片、文字与图形共同遵守固定边界。

连接符、组合与导出

使用“插入 → 形状 → 连接符”连接框的连接点，随后拖动一个框，检查线端能否跟随移动。普通直线不一定附着在框上。箭头方向需要与计算方向一致，线交叉过多时应调整对象位置。

复制对象 Ctrl+D 新对象保留原大小和样式

独立项目：猫狗识别

使用 Oxford-IIIT Pet 的猫狗标签，在 Kaggle 或本地建立自己的 PyTorch 分类程序。确定数据读取与标签对应、保存训练/验证/测试划分，选择一个能输出两个 logits 的模型，自行编写训练、验证、检查点保存与测试代码。可以查阅 PyTorch 文档和课程短练习，写清借鉴的代码来源。

至少保留训练和验证曲线、测试样本数、准确率、混淆矩阵和若干错误照片。调整一个明确因素，例如学习率或训练增强，固定数据划分后比较两次实验。计算资源有限时可使用明确记录的子集；两个方案使用相同子集，并说明数据规模。

提交可从头运行的项目代码或 Notebook、配置与划分、实际预测和图表，以及一张可编辑的 PPT 流程图和一页结果展示。流程图应画出你自己的图像处理、模型与输出关系；结果页至少包含一个指标和一个具体样例。项目完成标准是程序与结果能被解释和复查，不设置脱离数据规模的统一高准确率门槛。
