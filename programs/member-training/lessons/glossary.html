数据与计算

术语 含义
张量 / tensor 有形状与数据类型的多维数值对象；图像批量常采用 B×C×H×W。
logits 模型的原始分数；分类交叉熵和二元交叉熵各自需要匹配的输入形式。
梯度 / gradient 损失对参数的导数，优化器据此更新参数。
batch / epoch batch 是一次送入的一组样本；epoch 是遍历一次训练集合。
checkpoint 保存的参数及相关配置，应注明选择所依据的验证规则。
mask / trimap 像素标注。Oxford-IIIT Pet 的1/2/3分别为前景、背景、待定边界。
Dice / IoU 前景重叠指标。先统一有效像素和空前景约定，再汇总。

病理与研究记录

术语 含义
H&E 苏木精—伊红染色，常用于观察组织形态。
IHC / HER2 免疫组织化学 / 人表皮生长因子受体2；前者为方法，后者为本项目目标蛋白。
WSI / patch 全切片图像 / 从图像中取得的局部图块。
配对 / 配准 对应的输入目标关系 / 将组织位置对齐的空间处理。
L1 / RGB MAE 连续颜色的平均绝对误差；记录像素范围和评价区域。
对照实验 明确改变因素，并保存共同条件和实际观察。
文献证据 能定位到原文段落、图、表的具体依据。
