安装与环境

从 Anaconda 官网下载安装程序。Windows 安装后打开 Anaconda Prompt，运行下面的命令检查工具是否可用。

conda --version
python --version

为练习创建单独环境。这里固定 Python 3.11 作为这组示例的版本；已有项目按其依赖要求选择版本。

conda create -n kydw-start python=3.11
conda activate kydw-start
conda install numpy pandas matplotlib scikit-learn jupyter

命令提示符前出现 (kydw-start)，表示当前使用这个环境。NumPy 处理数组，pandas 处理表格，Matplotlib 绘图，scikit-learn 提供常见机器学习工具。

使用 Python 官网安装包

也可以从 Python 官网安装解释器，并为项目建立虚拟环境。在项目文件夹中运行 python -m venv .venv，在 VS Code 中选择该环境，再使用 python -m pip install pandas matplotlib 安装所需库。两种方案选一种即可。

VS Code 运行

  1. 安装 VS Code，在扩展页安装 Microsoft 发布的 Python 扩展。使用 Notebook 时再安装 Jupyter 扩展。
  2. 新建项目文件夹，用“文件 → 打开文件夹”打开。创建 sample_count.py。
  3. 按 Ctrl+Shift+P，执行 Python: Select Interpreter，选择 kydw-start 对应的解释器。
  4. 输入下方程序并保存，点击右上角 Run Python File，在终端查看输出。
sample_ids = ["cell_01", "cell_02", "cell_03"]
print("样本数：", len(sample_ids))

输出应为“样本数：3”。在列表中增加一个样本编号，再运行一次，观察数量变化。文件保存和程序运行是两个动作，修改后需要重新运行。

Notebook 与排错

在 VS Code 中新建 practice.ipynb，选择右上角内核，再添加代码单元格。每个单元格左侧的运行按钮只执行该块；后面的块可以使用前面已经定义的变量。重启内核后，变量需要重新运行生成。

现象处理
提示没有某个库核对所选解释器，在同一环境安装库
找不到文件查看报错路径，确认文件名、后缀与工作目录
变量没有定义运行定义变量的上方代码块，检查拼写
中文乱码以 UTF-8 保存文件，核对读取编码
结果没有改变确认保存了修改并重新运行相应代码块
