课程与练习

AI Python for Beginners 是 DeepLearning.AI 的 Python 入门课程。学习时关注变量、列表、循环、函数、文件读取，以及如何向 AI 描述一个具体的代码修改任务。

打开课程官网，查看课程介绍与当前可访问的单元。运行平台、访问方式和练习权限在课程页面中查看；已提供在线环境的单元可以直接在网页运行。

视频中的示例运行后，改一个输入再执行。例如把样本列表由三项变为五项，或只输出满足某个数值条件的记录。运行结果能直接检验你对代码的理解。

AI 辅助修改

有效的代码请求需要提供输入、希望改变的操作和期望输出。下面是一段可用于本地或 Notebook 的小练习。

scores = [0.2, 0.8, 0.65, 0.4]
threshold = 0.5
selected = [score for score in scores if score >= threshold]
print(selected)

这组数字是教学示例。阈值为 0.5 时输出 [0.8, 0.65]。把阈值改成 0.7，再比较输出。

可以让 AI“把这段程序改成同时输出符合条件的样本序号，序号从 1 开始；保留 scores 和 threshold 这两个变量”。运行后，逐项对照原始列表，检查序号是否正确。报错时提供完整错误文字与相关代码即可。
