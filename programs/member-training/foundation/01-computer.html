操作与文件

截图、查找与窗口切换

讨论一张曲线或一条报错时，截图能保留清楚的文字。截取问题所在区域，保留坐标轴、完整报错或必要的上下文，再粘贴到文档或消息中。

在 PDF 中查找 segmentation，可以定位分割相关段落。资源管理器中的搜索则查找磁盘文件，例如输入 *.pdf 查看当前文件夹内的 PDF。

后缀与编码

文件后缀说明文件格式。Windows 资源管理器中打开“查看 → 显示 → 文件扩展名”，就能区分 report.docx 和 report.pdf。把后缀直接改名不会完成格式转换；Word 文档需要用“导出”生成 PDF。

格式常见内容使用方式
.pdf论文和导出的报告浏览器或 PDF 阅读器
.docx / .pptx可编辑报告 / 幻灯片Word / PowerPoint
.csv按行列保存的数据Excel 或 Python
.py / .ipynbPython 程序 / NotebookVS Code、Jupyter 或 Kaggle
.zip打包的多个文件解压后打开其中的文件

CSV 中文乱码通常与字符编码有关。在 Excel 中用“数据 → 从文本/CSV”导入，并选择 UTF-8；在 VS Code 中可点击右下角的编码名称，以正确编码重新打开文件。

软件与网络

下载与运行工具

官网下载页通常按 Windows、macOS、Linux 区分安装包。使用学校提供的 Office 等软件时，从本校软件服务或账户入口获取许可。安装后，在开始菜单或应用列表中搜索软件名称即可打开。

VS Code 是代码编辑器，Python 解释器负责运行代码。安装编辑器不等于安装了 Python。需要本地运行时，按Python 安装与使用配置；只做网页练习可以使用 Kaggle。

PyCharm 也可用于 Python 开发。快速上手阶段选择一个编辑器即可；已有熟悉的工具可以继续使用。

浏览器、插件与访问

论文数据库可能要求学校账户或校园网络。校外访问时，使用本校图书馆提供的远程访问入口。Google Scholar 等服务的访问情况与网络有关。参加实践体验篇或进阶教学篇时，再按学习基础配置 Kaggle 环境；快速上手篇无需完成这些准备。

浏览器扩展为浏览器增加功能，例如 Zotero Connector 可以保存当前论文条目。通过浏览器官方扩展商店搜索名称、核对开发者，安装后在扩展菜单中固定图标。仅安装当前需要的功能。

工具与教程

Word 用于报告，Excel 用于表格与计算，PowerPoint 用于流程图和海报。官方说明适合查某个菜单；视频适合跟着完成一组操作。搜索时带上软件名称、版本和具体动作，例如“Word 图片题注 交叉引用”。

工具本页内可直接尝试的操作进一步学习
Word输入报告题目与两段正文，为小标题应用“标题 1”样式Word 图文教程
Excel在 A1、B1 输入 sample_id、score，向下填入几条示例记录，再选中数据插入柱形图源教程推荐的视频
PowerPoint插入矩形与文本，复制对象，用“对齐”统一位置PPT 绘图教程

CSDN、B 站、知乎等平台可用于寻找操作演示。复制命令前，核对软件版本、输入文件和预期输出。图书与论文可通过学校图书馆、出版社开放全文、作者主页或机构仓储获取。
