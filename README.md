# KYDW_TRY

KYDW（科研大王）学生自主运营的静态网站，面向团队介绍、项目展示、本科生科研入门体验和生医工专业信息整理。

## 内容结构

- `index.html`：团队主页，先说明 KYDW，再展示团队资源、项目与活动。
- `team/`：团队介绍、成果、成员去向、活动体系与负责人子页面。
- `experience/`：本科生科研入门体验项目主页、按周分组的项目目录和项目详情页；当前公开目录登记项目 00—05，项目 00 只有体验版，项目 01—05 在内容结构中保留体验版与进阶版，但进阶版当前全部锁定。后续项目继续沿用同一目录结构。
- `experience/teaching/`：已登记项目的体验教学 HTML；当前只发布体验版教学入口。进阶教学源文件暂存于仓库外的本地内部归档，未进入 GitHub Pages。
- `experience/practice/`、`experience/answers/`：体验版实践 Notebook 与实践项目参考答案。
- 已开放的体验项目实践卡同时提供本地 Notebook 下载和对应 Kaggle 路径；Notebook 标题按项目编号统一为 `KYDW_TRY_A00`、`KYDW_TRY_A01` 等，后续项目继续追加。首选方式是在 Kaggle 打开公开 Notebook，点击“复制并编辑”保存到自己的账户，再运行和修改；下载到电脑运行是补充方式。网页中的参考输出来自对应实践项目参考答案中保存的结果。尚未开放的项目不提供公开材料入口。
- 进阶实践、进阶实践项目参考答案、设计报告模板、参考设计报告及进阶说明文件：当前全部保存在仓库外的本地内部归档，用户明确开放后再按维护手册恢复并发布。
- `programs/`：KYDW科研入门培训、山东大学本科生暑期名校课程-神经影像学与人工智能、复旦大学秋季学期本科生践悟课程和生物医学人工智能专题交流的独立说明；山东大学本科生暑期名校课程-神经影像学与人工智能的各项实践另有对应的 `sdu-lesson-*` 子页面，分别进入对应 Kaggle Notebook。
- `programs/research-skills.html` 与 `programs/research-skills/`：科研技能入门与查缺补漏项目，包含新人入组、课程实践和长期科研常用的十二个章节。
- `recruitment/`：论文研究项目的历史招募时间线与统一详情页；课程、培训和一般活动不进入该合集。
- `resources/`：资源中心合集页；专业解读、项目与活动资料、教学文档库作为可扩展合集管理，教学文档库另含“科研基础环境准备”页面，后续有真实公告内容时再加入公告子合集。
- `professional/`：资源中心下的专业解读合集，当前包含生物医学工程专业介绍和独立的专业答疑页面。
- `content.js`：站点的结构化内容层；项目名、状态和文案应优先在此修改。
- `site.js` / `styles.css`：页面渲染与统一视觉样式。
- `SITE-MAINTENANCE.md`：逐页职责、GitHub 与 Notion 对照、联动关系、新增文档与发布检查的统一维护入口。
- `docs/site-architecture.md`：页面职责、内容联动关系和后续维护规则。
- `docs/DESIGN-LINKAGE.md`：页面、合集、区块、单一数据源和教学材料之间的设计关系与可扩展规则；涉及联动的需求先查此文档。
- `docs/experience-materials.md`：体验项目原材料、网站编号、页面路径和替换规则。
- `docs/promotions/`：面向公众号、普通群聊和项目专属群的宣传文案；项目时间、开放状态和入口变化时同步检查。

## 内容组织

- 体验版在 Notebook 中完成和补全指定内容，不要求提交报告；进阶版需要自行设计或选择方法、完成实践并提交设计报告，说明方法选择、验证设计和结果判断。当前进阶版不公开。
- 顶部导航为：主页、团队介绍、项目与活动、资源中心、人员招募；具体专业、行业和细分方向作为资源中心内专题继续增加。
- GitHub Pages 集中提供网站正文、项目说明、教学材料和保存的参考输出；实践代码优先在 Kaggle 中打开、复制到个人账户后运行和修改，下载 Notebook 仅作为补充方式。
- 山大、复旦等模块分别介绍学习与合作项目。
- 生医工页面集中整理专业认知、升学、就业和费用主题。
- 网站公开资料免费阅读，请勿用于牟利性销售。

## 本地预览

这是纯静态站点。可在仓库根目录运行任意静态文件服务器，或直接打开 `index.html` 查看主体页面。
