# KYDW_TRY

本科生科研入门体验项目的 GitHub Pages 静态网站初版框架。

## 当前内容

- `index.html`：项目首页，使用项目总介绍作为内容基准。
- `weeks/week-01.html` 至 `week-05.html`：按周的一级项目介绍页。
- `site.js`：项目数据和页面渲染配置，后续调整项目顺序、状态和链接时优先修改这里。
- `styles.css`：全站统一样式，不依赖外部框架、图片或 CDN。
- `lessons/index.html`：教学材料入口；新的 HTML 材料到位后再接入。

## 重要边界

当前目录中的旧版 HTML 全部排除，不作为内容、结构、样式、图片、链接或交互设计来源。教学二级页面等待新的 HTML 材料。

## GitHub Pages

仓库创建后，将默认分支的 Pages 来源设置为 `/(root)`，即可直接发布 `index.html`。本框架使用相对路径，适合项目站点地址。

## 当前项目分组

第 1–6 项暂按两周各 3 项建立框架，第 3–5 周预留后续方向。最终周次和项目顺序可只修改 `site.js`，无需重写页面。
