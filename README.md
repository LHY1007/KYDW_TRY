# KYDW_TRY

KYDW（科研大王）学生自主运营的静态网站，面向团队介绍、项目展示、本科生科研入门体验和生医工专业信息整理。

## 内容结构

- `index.html`：团队主页，集中展示团队、培训/合作模块、科研体验和专业说明。
- `team/`：团队背景、活动、成果、成员去向与负责人信息；成果与去向默认折叠。
- `experience/`：本科生科研入门体验项目主页、按周分组的项目目录和 01—15 方向页。
- `experience/advanced/`：五份进阶教学 HTML，保留自包含交互内容。
- `programs/`：KYDW 科研入门培训、山大/复旦方向和 Bio-AI Workshop 的模块说明。
- `resources/`：资源中心合集页；专业解读、升学资源、项目介绍和科研入门培训均作为可扩展子合集管理。
- `professional/`：资源中心下的专业解读合集，当前包含生医工专业介绍、升学/就业/费用常见问题和按年级整理。
- `content.js`：站点的结构化内容层；项目名、状态和文案应优先在此修改。
- `site.js` / `styles.css`：页面渲染与统一视觉样式。

## 内容组织

- “体验版 → 进阶实践 → 方向报告 → 课题组跟学”是一条完整的学习路径；申请加入 KYDW 按团队活动安排进行。
- 顶部导航只放合集：团队、科研体验、项目与活动、资源中心；具体专业、行业和细分方向作为合集内专题继续增加。
- GitHub Pages 集中提供网站正文、项目说明和教学材料；实践代码如在 Kaggle 开放，则从对应项目页跳转。
- 山大、复旦等模块分别介绍学习与合作项目。
- 生医工页面集中整理专业认知、升学、就业和费用主题。
- KYDW 组内资源永久免费。

## 本地预览

这是纯静态站点。可在仓库根目录运行任意静态文件服务器，或直接打开 `index.html` 查看主体页面。
